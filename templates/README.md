# Templates

Modelos genéricos, sem conteúdo específico de nenhum curso, para criar um novo curso ou uma nova aula sem precisar tomar decisões estruturais adicionais. Copie o arquivo relevante para o destino e substitua os campos entre `<>`.

| Template | Onde usar |
|---|---|
| [`README.md.template`](README.md.template) | Raiz de um novo curso (`<curso>/README.md`). |
| [`conteudo.md.template`](conteudo.md.template) | Conteúdo de uma nova aula (`<curso>/aula-XX/conteudo.md`). |
| [`exercicios.md.template`](exercicios.md.template) | Exercícios de uma nova aula (`<curso>/aula-XX/exercicios.md`) — sempre 10 questões. |
| [`questionario.md.template`](questionario.md.template) | Avaliação final de um novo curso (`<curso>/questionario.md`). |

Ver a convenção completa de estrutura em [`../README.md`](../README.md#️-arquitetura-do-repositório).
